# PytestTutorials

![Pytest](https://img.shields.io/badge/Pytest-Testing-blue)

Welcome to **PytestTutorials**! This repository contains detailed tutorials and examples to help you master **pytest**, a powerful Python testing framework. 🚀

## 📌 Features
- **Basic pytest usage** – Writing and running test cases
- **Assertions** – Using Python’s `assert` statement
- **Fixtures** – Setup and teardown automation
- **Parameterization** – Running tests with multiple inputs
- **Skipping and Expected Failures** – Controlling test execution
- **Mocking** – Using `pytest-mock` for unit testing
- **Code Coverage** – Measuring test coverage with `pytest-cov`
- **Parallel Execution** – Speeding up tests with `pytest-xdist`


## 🚀 Getting Started
### 1️⃣ Clone the Repository
```bash
git clone https://github.com/Ashwini-Dubey/PytestTutorials.git
cd PytestTutorials
```

### 2️⃣ Install Dependencies
```bash
pip3 install pytest pytest-xdist pytest-cov
```

### 3️⃣ Run Tests
Run all tests:
```bash
pytest
```


### 4️⃣ Run Tests with Coverage
```bash
pytest --cov=src
```
Generate an HTML coverage report:
```bash
coverage html
```

### 5️⃣ Run Tests in Parallel
```bash
pytest -n 4  # Runs tests in 4 parallel threads
```
